# Sneha Dubey · Product Owner portfolio

Personal portfolio site: profile, résumé and product case studies.

- `index.html`: home page (hero, case files, how I work, résumé)
- `projects/`: one case-study page per project
- `assets/site.css`: shared styles
- `assets/<project>/`: screenshots per project

To add a project: copy the `PROJECT CARD` block in `index.html`, add a page in `projects/`, and put its screenshots in `assets/<project>/`.

Hosted with GitHub Pages.
